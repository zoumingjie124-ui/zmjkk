### 0.1 三层过温阈值链（选型硬约束）

三个阈值必须严格递增，**硬件永远高于软件，软件永远高于目标**：

| 层 | 阈值 | 由谁决定 | 作用 |
|----|------|----------|------|
| 目标温度上限 | **70℃** | 固件 `CTRL_TARGET_MAX_C` | 用户能设到的最高值 |
| 软件联锁 | **75℃**（腔温） | 固件 `CTRL_SAFE_LIMIT_C` | 超温立即关加热、开风扇、锁 FAULT |
| 硬件过温开关 | **85℃ 左右** | KSD9700 / KSD302 选型 | 软件失效时的最后一道断流 |

**为什么不能选 50℃ / 60℃**：目标可设到 70℃，开关若在 50℃ 动作，正常加热就被切断，
现象是"加热一会儿就断、过一会儿又通"，极易被误判成固件故障。

#### 0.1.1 买了 PTC（100℃ 自限温）时，110℃ 开关等于没装

PTC 的表面温度被居里点锁住，**上不去 110℃**。结论只有两种，必须选一个并写清楚：

| 方案 | 做法 | 后果 |
|------|------|------|
| **A（推荐）** | 换成 **85℃ 常闭**，装**腔内空气侧**（靠近加热片但不贴铝壳） | 空气在 PWM 卡死时会继续升到 85℃ → 真正独立动作，与软件 75℃ 形成 10℃ 梯度 |
| B | 保留 110℃ 贴加热片铝壳 | **永远不会动作**（PTC 到 100℃ 就自限温）；它只对"非 PTC 类故障"有意义。此时对外**只能写两层软件保护 + PTC 自限温，不能写三层** |

> 为什么 A 不能贴在铝壳上：满功率时铝壳表面本就 90~100℃，85℃ 开关会**频繁误断**，
> 目标温度永远到不了。装在空气侧才能既避开误断、又能在失控时动作。

#### 0.1.2 KSD / 自恢复保险丝都是"自恢复型"，不是锁定

两者到温/过流断开、降温（或冷却）后**自动复位**，所以它们提供的是**限温**，不是**锁定**：

- 会反复"断开—降温—复位—再加热"，这是正常机理，不是故障；
- 真正的"停机等人确认"由固件 `FAULT` 状态负责（`Control_AckFault()` 才解除）；
- 因此 Gate 1-4 的判据是"**到温能断流**"，不是"断开后永久不恢复"。

### 0.2 PTC 加热片：限温点决定高温段还能不能控

PTC 在居里点附近电阻急剧上升、功率骤降：

- 限温点 100℃、目标 70℃ 时，70℃ 附近功率可能只剩额定的 **30~50%**（近居里点更低）；
- 控不住还只是"慢"，更麻烦的是**误触发热失控判据**：温度卡在 68℃、目标 70℃ 时
  `target - temp > 3℃`、占空比 ≥80%、60s 温升 < 2℃ —— 三条全中，固件判 `RUNAWAY`。
  这不是固件 bug，是**选型把保护逻辑逼到了它的判据边上**。

**对策（按优先级）**：

1. 首次闭环把目标设 **≤60℃**（离居里点留 40℃），确认能稳定收敛再往上试；
2. 用 `tune_helper.py` 先做开环阶跃，量出 70℃ 附近的实际功率，再决定目标上限；
3. 若确实需要 70℃，改用限温点 ≥120℃ 的 PTC，或非 PTC 的陶瓷片/绕线电阻（功率线性）。

> 回填前，`PA8` 只允许接 LED 假负载；`WIRING.md` §2 的分压拓扑与 `sensor.c` 的换算参数必须与实物一致，否则读数无效（固件会因换算超范围判 invalid 并锁 FAULT，不会盲目加热）。

## 2. NTC 温度采样（默认真实传感器）

```
   3.3V ──[ R_fixed 10kΩ 1% ]──┬── PA0 (ADC1_IN0)
                               │
                        [ NTC 10kΩ B3950 ]
                               │
                              GND
```

- 分压公式：`V(PA0) = 3.3 × R_ntc / (10k + R_ntc)`
- 固件换算：`R_ntc = 10k × ADC / (4095 − ADC)`，再套 Beta 公式（默认 B=3950、R0=10k@25℃）
- **参数未经实测校准**：若你的 NTC 是 5k/100k 或不同 B 值，改 `Hardware/sensor.c` 顶部宏即可
- 故障保护（第二轮审查更新）：PA0 贴轨（≤5 或 ≥4090，即未接 NTC/开路/对地短路）或换算温度超出 `[-40℃, 150℃]` 时，`Sensor_Read()` 返回 `is_valid=0`，控制层在 `INIT` 或 `RUNNING` 阶段立即进入 `FAULT` 锁死（关加热、开风扇、OLED 显示 `FLT T:  ERR`），**绝不自动切换为模拟模式**；软件模拟模式仅可通过编译期宏 `SENSOR_SIM_ENABLE=1` 显式开启，且开启时软件输出许可（闸门）强制关闭 PA8。

## 3. 加热器 / 风扇功率驱动（低边 N-MOS）

```
   负载电源 +  ──────────────┬──────────────┐
                             │              │
                        [ 加热器 ]      [ 风扇 ]──┐
                             │              │   │ 续流二极管
                             ▼              ▼   │ (SS34，风扇用)
                        ┌─────────┐   ┌─────────┐│
   PA8 ─[100Ω]─┤G  Q1   │   ┌─────────┐   Q2  ││
                │  N-MOS  │   │  N-MOS  │        │
   ┌──[10kΩ]────┤S        │   │         │        │
   │            └────┬────┘   └────┬────┘        │
  GND               GND           GND           │
                                                 │
   负载电源 −  ────────── 与 MCU GND 单点共地 ◄──┘
```

| 元件 | 作用 | 参数原则 |
|------|------|----------|
| 栅极串联电阻 100Ω | 抑制栅极振铃 | 51~220Ω 均可 |
| 栅源下拉 10kΩ | **上电默认关断**（复位期间 GPIO 浮空） | 必须装，安全关键 |
| N-MOS | 低边开关 | 逻辑电平型；`V_DS ≥ 2×负载电压`；`I_D ≥ 3×负载电流`；**看 `R_DS(on)@V_GS=2.5V`** 而非 10V 值；`P=I²·R_DS(on) < 0.5W` 可免散热片 |
| 续流二极管 | 风扇断电瞬间泄放 | 肖特基，`I_F ≥ 风扇额定电流`，反向耐压 ≥ 负载电压 |
| 负载电源去耦 | 抑制电机瞬态 | 入口 100µF 电解 + 100nF 陶瓷 |

**未确定型号的原因**：加热器电压/功率、风扇电流尚未提供（见 `DEVELOPMENT_PLAN.md` 阶段 0 清单）。确定后按上表计算再选型。

> ⚠️ 真实加热器接入前，PA8 只能接 LED+限流电阻做假负载，先用示波器确认 1kHz/占空比正确。

## 4. 共地与供电

| 要求 | 说明 |
|------|------|
| 单点共地 | 负载电源 GND 与开发板 GND 只在驱动板处连一次，避免地环路把开关噪声灌进 ADC |
| 分开供电 | MCU/OLED 走开发板 3.3V；加热器/风扇走独立负载电源 |
| 上电顺序 | 先给 MCU，再给负载电源；断电反之 |
| 电流核算 | `I_load = P_heater / V_load + I_fan`，负载电源额定电流 ≥ 1.3 × I_load |

## 5. 上电前检查清单

1. 万用表量 PA8、PB0 对 GND：**上电瞬间必须为 0V**（栅极下拉生效）
2. 量 3.3V 与负载电源之间：**不应导通**（两路电源未短接）
3. 量负载电源 GND 与 MCU GND：应导通（共地已接）
4. NTC 分压中点电压：室温下约 1.65V（10k/10k 分压）
5. 首次上电只接 MCU + OLED + 按键 + USB-TTL，**不接负载**
