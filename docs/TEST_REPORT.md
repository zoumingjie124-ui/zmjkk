## 3. 宿主机单元测试（【模拟】，实际运行）

### 3.1 PID（`tests/test_pid.c`，20 项全过）

| 用例 | 断言 | 实测值 |
|------|------|--------|
| T1 阶跃响应 25→45℃/600s | 稳态误差 < 0.5℃、超调 < 3℃、输出恒在 [0,100] | 误差 **0.005℃**、超调 **0℃**、占空比收敛 50% |
| T2 输出限幅 | 大误差下 u 精确 = 100 / = 0 | 100.0 / 0.0 ✅ |
| T3 积分抗饱和 | 饱和期积分冻结；反向误差 1 步退饱和；积分硬限幅生效 | 积分 0.0000→ 反向 1 步 u=0；硬限幅 5.0000 ✅ |
| T4 异常输入 | NaN/越界返回 0、置故障、状态不被污染 | 4 种异常全拦截，积分保持 2.5000，恢复后正常续算 2.7500 ✅ |

### 3.2 参数编解码（`tests/test_param.c`，21 项全过）

| 用例 | 结果 |
|------|------|
| CRC32 已知向量 `"123456789"` | 0x0376E6E7 ✅（CRC-32/MPEG-2 标准值） |
| 镜像布局 | 28 字节、magic `31 4D 43 54`、version 1、45.0f=`00 00 34 42` ✅ |
| 往返一致 | target/kp/ki/kd 位级一致 ✅ |
| 损坏检测 | 载荷翻 bit → CRC 不符(2)；magic 破坏(1)；版本破坏(1)；空白 Flash 全 FF(1) ✅ |
| 边界值 | 0/0/0/0 与 70/50/5/20 均可正确往返 ✅ |

### 3.3 协议编解码（`host/test_protocol.py`，46 项全过）

- CRC16 已知向量 `"123456789"` = 0x29B1（CCITT-FALSE 标准值）
- 帧布局、总长 = 6+LEN、CRC 覆盖范围
- 整包/逐字节/7 字节不规则切分三种投喂方式均能解析出 4 帧
- 坏 CRC（尾字节、载荷翻 bit）→ 丢弃并计数
- LEN=33 超限拦截、LEN=32 上限接受、客户端组帧拒绝超长载荷
- 噪声中重同步（伪帧头 `AA 00`/`AA A5` 后仍能抓到真帧）
- 状态帧 25B 解码；`-999` 哨兵正确解出 FLT/SENSOR
- 客户端越界校验（目标 70.5 拒绝、kp 60 拒绝、NaN 拒绝）
- **2000 次随机字节流模糊测试：零异常**
- 命令编码向量：START 6B、SET_TARGET 10B、SET_PID 18B、解析回读一致

### 3.4 链路演练（`host/monitor_cli.py --demo`，30 帧）

一阶惯性模型合成状态帧 → 真实 `protocol.Parser` → 终端渲染，日志见 `host/monitor_demo_log.txt`。

## 6. 已知边界与限制

1. NTC 参数（10k/B3950/分压 10k）为**假设值**，未实测校准，绝对精度未验证。
2. PID 参数 Kp=8/Ki=0.10/Kd=1.5 仅与软件模拟对象匹配，真实加热器需重新整定。
3. 模拟模型为单容一阶惯性，未建模环境扰动与热辐射非线性。
4. Flash 写入寿命约 10k 次，当前仅在用户显式保存时写，正常使用无风险。
5. 通信无重传机制（上位机侧建议 300ms 超时重发，见 PROTOCOL.md §1）。
