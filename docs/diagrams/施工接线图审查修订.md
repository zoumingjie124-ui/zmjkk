## 2. 必须修改图纸

1. **补画 85℃ 常闭空气侧温控开关**：与 110℃ 常闭 KSD 串联在加热器正极回路。85℃ 开关装在腔内空气侧，不能贴 PTC 铝壳；110℃ 开关贴 PTC 铝壳。任一动作都应切断加热片电流。当前采购清单若只有 110℃ KSD，则 85℃ 开关属于尚未落实的缺件，不能在图上画成“已购/已装”。
2. **PB0 标注改为“GPIO 开关量”**：当前 `Hardware/fan.c` 只实现 Fan_On/Fan_Off，固件没有启用 TIM3_CH3 PWM。可在注释中写“未来可扩展调速”，但不能标成当前 PWM 功能。
3. **IRLZ44N 标为“待 3.3V 栅压验证”**：不能只凭 Logic Level 或阈值电压判断充分导通。应核对数据手册在实际 VGS（优先有 2.5V/3.0V 最大 RDS(on) 保证值）下的导通电阻，并在实物上测量 MOSFET 的 VGS、VDS 和温升。未验证前，不接真实加热负载。
4. **5A 保险丝标注为候选值，不是已验证定值**：按 PTC 冷态电流、风扇电流、适配器能力、导线和端子额定值以及保险丝时间-电流曲线复核。保险丝放在 12V 输入分叉之前。
5. **风扇二极管标清极性**：若确认采用并联续流二极管，阴极（色环端）接 +12V，阳极接风扇负端/MOSFET Drain；并核对实际风扇类型及额定电流。不得把二极管画成串联。
6. **供电图保持单一来源**：调试版本由 ST-Link 3V3 给开发板供电；USB-TTL 只接 TXD、RXD、GND，USB-TTL 的 5V/3V3 悬空。12V 只供功率负载，12V 负极与 MCU GND 在驱动板单点共地；禁止把 12V 接到 MCU 3V3。
7. **NTC 分压标出电阻位置与方向**：3V3—10kΩ 1% 固定电阻—PA0 分压点—NTC—GND。PA0 不得直接接 3V3。室温、NTC 与固定电阻均约 10kΩ 时，PA0 约为 1.65V（仅作初检参考）。

## 3. 上电前验证顺序

1. 不接 12V 负载电源；只接 MCU、OLED、按键、NTC、ST-Link 和 USB-TTL（三根信号线）。
2. 测开发板 3V3；确认 USB-TTL 的 5V/3V3 没有接入开发板。
3. 测 NTC 分压点，室温下记录 ADC 原始值和万用表电压；确认 OLED 温度与独立温度计大致一致后再做校准。
4. PA8/PB0 暂接 LED 假负载，验证 PA8 1kHz PWM、PB0 高低电平、按键短按/长按行为。
5. 单独验证 MOSFET Gate 下拉：MCU 复位、未供电及固件输出关闭时 Gate 均应保持低电平。
6. 确认 85℃/110℃ 两个温控开关均为常闭且串联在加热支路后，先做低风险限流测试，再连接 PTC。
7. 最后才接风扇和加热器，首次闭环目标温度不高于 60℃，持续监测 MOSFET、端子、导线和 PTC 温升。

## 4. 依据文件

- `Core/Inc/main.h`：GPIO 宏定义。
- `Core/Src/gpio.c`：PB12/PB13/PB14 内部上拉；PA8/PB0 默认低。
- `Core/Src/tim.c`、`Hardware/heater.c`：PA8 / TIM1_CH1，1kHz PWM，输出闸门默认关闭。
- `Hardware/fan.c`：PB0 仅开关量。
- `Hardware/key.c`：按下接地的低有效按键逻辑。
- `Hardware/sensor.c`、`Core/Src/adc.c`：PA0 ADC1_IN0、8 次平均、10k/B3950 默认换算参数。
- `Hardware/oled.c`：PB6/PB7 软件 I²C，地址字节 0x78。
- `docs/WIRING.md`：NTC、低边驱动、过温保护与供电原则。
