# 硬件接线表（WIRING）

> 芯片：STM32F103C8T6（LQFP48，3.3V 逻辑）
> 原则：**任何加热器/风扇都必须经过功率驱动（MOSFET 低边），严禁直接接 GPIO。**

---

## 1. MCU 引脚分配

| 引脚 | 外设功能 | 方向 | 连接对象 | 备注 |
|------|----------|------|----------|------|
| PB6 | GPIO 开漏 | 输出 | OLED SCL | 软件 I2C，空闲为高 |
| PB7 | GPIO 开漏 | 输出 | OLED SDA | 软件 I2C，空闲为高 |
| PA8 | TIM1_CH1 | 复用推挽 | MOSFET 栅极（经 100Ω） | 1kHz PWM，0% 时呈低电平 |
| PB0 | GPIO | 推挽输出 | 风扇 MOSFET 栅极（经 100Ω） | 高=开；预留 TIM3_CH3 调速 |
| PA0 | ADC1_IN0 | 模拟输入 | NTC 分压中点 | 见 §2 |
| PA9 | USART1_TX | 复用推挽 | USB-TTL 的 RX | 115200 8N1 |
| PA10 | USART1_RX | 浮空输入 | USB-TTL 的 TX | |
| PB12 | GPIO | 上拉输入 | KEY1（对地） | 短按：启停/故障确认 |
| PB13 | GPIO | 上拉输入 | KEY2（对地） | 短按：切编辑项；长按：保存 |
| PB14 | GPIO | 上拉输入 | KEY3（对地） | 短按：+；长按：- |
| PA13/PA14 | SWDIO/SWCLK | — | ST-Link | **禁止挪用** |
| 3V3 / GND | 电源 | — | 开发板 3.3V / 地 | 与负载电源单点共地 |

## 2. NTC 温度采样（默认真实传感器）

```
   3.3V ──[ R_fixed 10kΩ 1% ]──┬── PA0 (ADC1_IN0)
                               │
                        [ NTC 10kΩ B3950 ]
                               │
                              GND
```

- 分压公式：`V(PA0) = 3.3 × R_ntc / (10k + R_ntc)`
- 固件换算：`R_ntc = 10k × ADC / (4095 − ADC)`，再套 Beta 公式（默认 B=3950、R0=10k@25℃）
- **参数未经实测校准**：若你的 NTC 是 5k/100k 或不同 B 值，改 `Hardware/sensor.c` 顶部宏即可
- 故障保护（第二轮审查更新）：PA0 贴轨（≤5 或 ≥4090，即未接 NTC/开路/对地短路）或换算温度超出 `[-40℃, 150℃]` 时，`Sensor_Read()` 返回 `is_valid=0`，控制层在 `INIT` 或 `RUNNING` 阶段立即进入 `FAULT` 锁死（关加热、开风扇、OLED 显示 `FLT T:  ERR`），**绝不自动切换为模拟模式**；软件模拟模式仅可通过编译期宏 `SENSOR_SIM_ENABLE=1` 显式开启，且开启时硬件输出总闸强制关闭 PA8。

## 3. 加热器 / 风扇功率驱动（低边 N-MOS）

```
   负载电源 +  ──────────────┬──────────────┐
                             │              │
                        [ 加热器 ]      [ 风扇 ]──┐
                             │              │   │ 续流二极管
                             ▼              ▼   │ (SS34，风扇用)
                        ┌─────────┐   ┌─────────┐│
   PA8 ─[100Ω]─┤G  Q1   │   ┌─────────┐   Q2  ││
                │  N-MOS  │   │  N-MOS  │        │
   ┌──[10kΩ]────┤S        │   │         │        │
   │            └────┬────┘   └────┬────┘        │
  GND               GND           GND           │
                                                 │
   负载电源 −  ────────── 与 MCU GND 单点共地 ◄──┘
```

| 元件 | 作用 | 参数原则 |
|------|------|----------|
| 栅极串联电阻 100Ω | 抑制栅极振铃 | 51~220Ω 均可 |
| 栅源下拉 10kΩ | **上电默认关断**（复位期间 GPIO 浮空） | 必须装，安全关键 |
| N-MOS | 低边开关 | 逻辑电平型；`V_DS ≥ 2×负载电压`；`I_D ≥ 3×负载电流`；**看 `R_DS(on)@V_GS=2.5V`** 而非 10V 值；`P=I²·R_DS(on) < 0.5W` 可免散热片 |
| 续流二极管 | 风扇断电瞬间泄放 | 肖特基，`I_F ≥ 风扇额定电流`，反向耐压 ≥ 负载电压 |
| 负载电源去耦 | 抑制电机瞬态 | 入口 100µF 电解 + 100nF 陶瓷 |

**未确定型号的原因**：加热器电压/功率、风扇电流尚未提供（见 `DEVELOPMENT_PLAN.md` 阶段 0 清单）。确定后按上表计算再选型。

> ⚠️ 真实加热器接入前，PA8 只能接 LED+限流电阻做假负载，先用示波器确认 1kHz/占空比正确。

## 4. 共地与供电

| 要求 | 说明 |
|------|------|
| 单点共地 | 负载电源 GND 与开发板 GND 只在驱动板处连一次，避免地环路把开关噪声灌进 ADC |
| 分开供电 | MCU/OLED 走开发板 3.3V；加热器/风扇走独立负载电源 |
| 上电顺序 | 先给 MCU，再给负载电源；断电反之 |
| 电流核算 | `I_load = P_heater / V_load + I_fan`，负载电源额定电流 ≥ 1.3 × I_load |

---

## 5. 上电前检查清单

1. 万用表量 PA8、PB0 对 GND：**上电瞬间必须为 0V**（栅极下拉生效）
2. 量 3.3V 与负载电源之间：**不应导通**（两路电源未短接）
3. 量负载电源 GND 与 MCU GND：应导通（共地已接）
4. NTC 分压中点电压：室温下约 1.65V（10k/10k 分压）
5. 首次上电只接 MCU + OLED + 按键 + USB-TTL，**不接负载**
