# App 层（应用层）

本目录在第一阶段为空，仅作结构占位。后续阶段在此添加：

| 文件（规划） | 职责 | 引入阶段 |
|--------------|------|----------|
| `pid.c/h` | PID 算法（纯 C，**不依赖 HAL**，可离线单元测试） | 阶段 4 |
| `control.c/h` | 控制状态机：自检/待机/运行/故障 + 安全联锁 | 阶段 4-5 |
| `menu.c/h` | OLED 菜单与按键交互 | 阶段 6 |
| `flash_param.c/h` | 参数掉电保存（F103 末页 Flash） | 阶段 7 |
| `comm.c/h` | USART1 帧协议，对接 Python 上位机 | 阶段 8 |

约束：App 层只依赖 Hardware 层接口，不直接操作寄存器；`pid.c` 例外——它连 Hardware 都不依赖。
