## 2. 修正 NTC 理论灵敏度 ✅

原文档写 **0.06 ℃/LSB**，偏高约 2.7 倍。正确推导（`docs/PREBOARD_TEST_PLAN.md` P1-4）：

```
dV/dT = Vcc·Rf/(Rf+R)² · dR/dT ,  dR/dT = −B·R/T²
25℃: R=10k, Rf=10k, Vcc=3.3V → dV/dT ≈ −36.7 mV/℃
1 LSB = 3.3/4095 = 0.806 mV → 0.806/36.7 ≈ 0.022 ℃/LSB
```

| 温度 | 15℃ | 25℃ | 35℃ | 45℃ | 60℃ |
|------|-----|-----|-----|-----|-----|
| ℃/LSB | 0.0216 | 0.0220 | 0.0246 | 0.0296 | 0.0430 |

另注明：8 次算术平均只把随机噪声降到 1/√8≈35%，**不改善量化误差**；判据中的 0.3℃ 峰峰 ≈ 25℃ 下 14 LSB。

## 4. NTC 断线关断延迟 🟡

静态分析（`PREBOARD_TEST_PLAN.md` P1-8）：断线 → 下一次采样（0~500ms）→ 同 tick 联锁关断 → CCR=0（1ms 内生效）；叠加最坏阻塞 140ms，**上界 ≈0.65s，典型 0~0.5s**。
实测方法：示波器单次触发 / PB1 翻转标记，重复 5 次取最大；判据 ≤0.7s。**尚未上板实测。**

## 5. IWDG 复位与 PA8 关断 🟡

静态分析（P1-9）：HardFault 内 `MOE=0` + 拉低 PA8（µs 级）；死循环靠 IWDG 0.67~1.33s 复位；复位后 PA8 浮空 + 10k 下拉 → MOS 关断。
**已知残余风险**：IWDG 窗口内加热器仍按最后占空比输出（最多约 1.33s），彻底消除需独立温控开关（未安装，见 `WIRING.md` §0）。
实测方法：制造死循环/暂停 CPU，示波器测复位时间与 PA8 电平，观察 `WDG` 标志。**尚未上板实测。**
