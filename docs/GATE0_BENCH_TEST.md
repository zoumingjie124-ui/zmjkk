# Gate 0 台架测试补丁（A/B 阶段故障注入）

> 用途：PA8 假负载验证 + 复位行为 + 传感器故障。测完把第 6 节记录表贴进 `docs/TEST_REPORT.md` §4。
> 器材：万用表 FY106A、LED ×1~2、330Ω、10kΩ、杜邦线、ST-Link。**不接 MOS，不接 PTC。**
> 状态：⏳ 待执行（本文是操作单，不是实测记录）

## 0. 前置条件

- 烧 `SENSOR_SIM_ENABLE=0` 的 REAL 固件（`Hardware/sensor.h`，默认值）。
  SIM 模式下 `Heater_EnableOutput()` 被强制为 0，**PA8 恒低**，且传感器恒 valid——A/B 全部无效。
- NTC 必须已接好再上电：REAL 模式下 NTC 开路会让上电直接进 `FAULT`，无法启动。
- 工程未冻结 IWDG（`Core/Src/iwdg.c` 无 `DBGMCU` 配置）：Keil 调试中点"暂停"＝程序卡死，约 1.3s 后自动复位。**这是预期行为，不是 bug**。

## 1. Step 0：先让板子活着（A/B 之前必须过）

目标：屏幕出现 `REAL` 与室温读数。**不接 LED、不接 MOS、不接 12V。**

### 接线（8 根，全低压）

| 从 | 到 | 说明 |
|----|----|------|
| 板 3V3 | 10kΩ 一端 | 分压上臂 |
| 10kΩ 另一端 | **PA0**（与 NTC 一脚同行） | 分压中点 |
| NTC 另一脚 | GND | |
| OLED VCC | 板 3V3 | **不接就不显示，判据无法验证** |
| OLED GND | 板 GND | |
| OLED SCL | **PB6** | 软件 I2C |
| OLED SDA | **PB7** | |
| ST-Link 3V3 / SWDIO / SWCLK / GND | 板 3V3 / PA13 / PA14 / GND | SWDIO=PA13、SWCLK=PA14，接反连不上 |

PA8、PB0 空着。

### 供电只留一路

ST-Link 的 3V3 接了板子 3V3，就**不要再插板子的 USB 口**，否则两个电源互相顶（可能反复复位或烧稳压器）。
USB-TTL 的 5V / 3V3 一律悬空，只接 TX、RX、GND。

### 烧录

1. `MDK-ARM\TempCtrl.uvprojx` → Options → C/C++ → Define：确认**没有** `GATE0_STAIR`
   （有的话 PA8 会输出 PWM，下面判据表第 3 条必然失败）
2. `Hardware/sensor.h` 的 `SENSOR_SIM_ENABLE` 保持 **0**
3. Rebuild（不要增量编译）→ 应 0 Error 0 Warning，`Code=18626`
4. Download

### 屏幕预期（布局来自 `App/Src/menu.c`，以实际屏幕为准）

```
STB T:23.5
SET:45.0
H:000% F:OFF
REAL UP:00042
```

### 判据

| # | 判据 | 不满足说明 |
|---|------|-----------|
| 1 | 第 4 行是 `REAL`（不是 `SIM`） | 烧成模拟固件，A/B 阶段全部无效 |
| 2 | 屏幕温度与环境温度差 ≤2℃ | R0/B/Rf 假设是否合理；差更多属"待校准"，不是故障 |
| 3 | 第 3 行 `H:000%`，PA8 对 GND = 0V | 待机不该有输出 |
| 4 | PA0 电压反算的温度 ≈ 屏幕温度（≤0.5℃） | 采样与换算链路一致 |

### 电压 ↔ 温度对照（R0=10k、B=3950、Rf=10k、Vcc=3.3V）

| 温度 | NTC 阻值 | PA0 电压 |
|------|----------|----------|
| 10℃ | 20.2 kΩ | 2.21 V |
| 15℃ | 15.8 kΩ | 2.02 V |
| 20℃ | 12.5 kΩ | 1.84 V |
| **25℃** | **10.0 kΩ** | **1.65 V** |
| 30℃ | 8.04 kΩ | 1.47 V |
| 35℃ | 6.51 kΩ | 1.30 V |
| 40℃ | 5.30 kΩ | 1.14 V |

25℃ 附近灵敏度 **−36.7 mV/℃**，即 ±2℃ ≈ ±73 mV。所以**不要用一个固定电压窗口去套**（1.55~1.75V 只对应约 23~27℃），而是按实测室温查表比对。

> 注意：屏幕温度本身就是由这个电压算出来的，两者**必然一致**——判据 4 验证的是"采样与换算实现无误"，判据 2 验证的是"假设参数与实物是否相符"。两者不能互相替代。

### 出问题对照

| 现象 | 原因 |
|------|------|
| 第 4 行 `SIM` | 烧错固件；改宏后 **Rebuild**（别增量） |
| 第 1 行 `T: ERR` | NTC 未接通 / 分压接反 / 虚接。量 PA0：≈3.3V 为开路，≈0V 为短路 |
| 上电直接 `FLT` | REAL 模式自检未过，同上查 NTC |
| OLED 全黑 | PB6/PB7 接反，或 OLED VCC 未接 3.3V |
| Keil 连不上 | SWDIO/SWCLK 接反；或 3V3/GND 未共地 |

## 2. 接线（PA8 假负载）

```
PA8 ── 330Ω ── LED 阳极(长脚)，LED 阴极(短脚) ── GND
PA8 ── 10kΩ ── GND            ← 下拉，没有它"复位时为低"测不准
可选：PB0 ── 330Ω ── LED2 ── GND    ← 同时观察"加热关 + 风扇开"
```

10k 下拉必须装：复位期间 PA8 是高阻态，没有下拉时万用表读数会漂。

## 3. 台架代码（阶梯占空比 10% → 50% → 90%）

放进 `Core/Src/main.c` 的 `while (1)` **末尾**（`Control_Tick()` 之后，否则会被状态机里的 `Heater_Off()` 覆盖）。
作用域内已有毫秒时间变量 `now`（`HAL_GetTick()`），无需额外声明。

```c
#if GATE0_STAIR
    /* Gate 0 台架专用：10% -> 50% -> 90% 阶梯，每 3s 换档。
       只接 LED + 330R + 10k 下拉，绝不接 PTC。
       用法：Keil -> Options -> C/C++ -> Define 加 GATE0_STAIR=1；测完删掉。 */
    {
      static const uint16_t stair[3] = {100u, 500u, 900u};
      static uint8_t  idx    = 0u;
      static uint32_t t_step = 0u;

      if ((now - t_step) >= 3000u)
      {
        t_step = now;
        idx = (uint8_t)((idx + 1u) % 3u);
      }
      Heater_EnableOutput(1);   /* 强制打开输出许可（绕过状态机，仅台架用） */
      Heater_SetDutyPermille(stair[idx]);
    }
#endif
```

**测完必须做三件事**：删掉 `GATE0_STAIR=1` 宏、确认正式固件不含这段、重新编译并核对 `Code` 尺寸回到 18626B。

> 这段代码**故意绕过状态机**：即使进了 `FAULT` 也照样输出 PWM。所以它只允许在"不接功率负载"的台架上用。

## 5. Step 2 / Step 3

### Step 2：复位行为（用**不带** `GATE0_STAIR` 的固件）

| 测试 | 操作 | 判据 |
|------|------|------|
| 手动复位 | 按住 RST，DC 档量 PA8 | **0 V**；松开后仍为 0（STANDBY 不加热） |
| 看门狗 | Keil 调试运行中点"暂停" | ≤1.3s 自动复位，调试断开，OLED 出现 `WDG` |
| 启动期间 | 上电盯 LED | 复位到 OLED 亮起全程不亮；**闪一下 = 有输出，属缺陷** |

### Step 3：传感器故障

前提：REAL 固件、NTC 接好、按 KEY1 进 RUNNING（此时 PA8 上 LED 应亮——室温远低于 45℃ 目标，PID 输出大）。

| 场景 | 操作 | 预期 | 判据 |
|------|------|------|------|
| 开路 | 拔掉 NTC 与 PA0 间的线 | PA0 被上拉到 3.3V（raw>4090 贴轨），`is_valid=0`，进 FLT | OLED 1s 内 `FLT`+`SEN`；PA8=0V；PB0=3.3V |
| 短路 | 杜邦线短接 NTC 两脚 | PA0=0V（raw<5 贴轨），进 FLT | 同上（3.3V 经 10k 到地仅 0.33mA，安全） |
| 误确认 | 故障未排除时按 KEY1 | 拒绝解除 | OLED `SENSOR STILL ERR`，仍 FLT（串口 ACK 6） |
| 正确恢复 | 插回 NTC，按 KEY1 | 回 `STB`，**不自动恢复加热** | 需再按一次 KEY1 才进 RUNNING |
