## 2. 修正 NTC 理论灵敏度 ✅

原文档写 **0.06 ℃/LSB**，偏高约 2.7 倍。正确推导（`docs/PREBOARD_TEST_PLAN.md` P1-4）：

```
dV/dT = Vcc·Rf/(Rf+R)² · dR/dT ,  dR/dT = −B·R/T²
25℃: R=10k, Rf=10k, Vcc=3.3V → dV/dT ≈ −36.7 mV/℃
1 LSB = 3.3/4095 = 0.806 mV → 0.806/36.7 ≈ 0.022 ℃/LSB
```

| 温度 | 15℃ | 25℃ | 35℃ | 45℃ | 60℃ |
|------|-----|-----|-----|-----|-----|
| ℃/LSB | 0.0216 | 0.0220 | 0.0246 | 0.0296 | 0.0430 |

另注明：8 次算术平均只把随机噪声降到 1/√8≈35%，**不改善量化误差**；判据中的 0.3℃ 峰峰 ≈ 25℃ 下 14 LSB。

## 4. NTC 断线关断延迟 🟡

静态分析（`PREBOARD_TEST_PLAN.md` P1-8）：断线 → 下一次采样（0~500ms）→ 同 tick 联锁关断 → CCR=0（1ms 内生效）；叠加最坏阻塞 140ms，**上界 ≈0.65s，典型 0~0.5s**。
实测方法：示波器单次触发 / PB1 翻转标记，重复 5 次取最大；判据 ≤0.7s。**尚未上板实测。**

## 5. IWDG 复位与 PA8 关断 🟡

**第三轮整改**：原实现只写 `GPIOA->BRR` 而 PA8 仍在 AF 模式——该写操作对引脚无效（评审指出，成立）。
现统一为 `Heater_PanicOff()`：MOE=0 → 停计数 → **PA8 切回通用推挽输出** → 拉低 → 开风扇 → `__DSB()`，
并由 `NMI/HardFault/MemManage/BusFault/UsageFault` 五个异常与 `Error_Handler()` 共同调用（不再有遗漏路径）。

静态分析（P1-9）：异常关断 µs 级；死循环靠 IWDG 0.67~1.33s 复位；复位后 PA8 浮空 + 10k 下拉 → MOS 关断。
**已知残余风险**：IWDG 窗口内加热器仍按最后占空比输出（最多约 1.33s），彻底消除需独立温控开关（未安装，见 `WIRING.md` §0）。
实测方法：制造死循环/暂停 CPU，示波器测复位时间与 PA8 电平，观察 `WDG` 标志。**尚未上板实测。**

## 8. 上板门禁（硬件到位后的强制顺序）

> 原则：**不允许跳级**。上一道门禁未全部通过，不得进入下一道。

### Gate 0 · LED 假负载（不接加热器、不接负载电源）

| # | 项目 | 判据 |
|---|------|------|
| 0-1 | PA8 正常输出 | 示波器：1kHz 方波，占空比与 OLED `H%` 一致（10%/50%/90% 各测一次） |
| 0-2 | 异常关断波形 | 人为触发 HardFault（如空指针跳转）→ PA8 在 µs~ms 内变低，且**无高电平毛刺**（重点看切换瞬间） |
| 0-3 | 看门狗复位波形 | 制造死循环 → PA8 最长 1.33s 内变低并复位；复位后 PA8 保持 0V；OLED 出现 `WDG` |
| 0-4 | SIM 模式不输出 | `SENSOR_SIM_ENABLE=1` 编一版 → 闭环运行，PA8 全程 0V（P1-10） |

**Gate 0 未过 → 停止，不得接真实负载。**

### Gate 1 · 独立过温保护 + 传感器故障

| # | 项目 | 判据 |
|---|------|------|
| 1-1 | 传感器断线 | REAL 模式闭环中拔 NTC → ≤0.7s 内 `FLT`、PA8=0、风扇 ON |
| 1-2 | 故障确认拒绝 | 传感器仍断时按 KEY1 → `SENSOR STILL ERR`，仍 `FLT`；串口 ACK 码 6 |
| 1-3 | 恢复流程 | 插回 NTC → 按 KEY1 回 `STB` → 启动 → 闭环恢复 |
| 1-4 | 独立温控开关 | 串联的常闭温控开关在设定温度动作，**切断加热回路**（用万用表/电流表确认断流），且动作后固件不可自行恢复 |

**Gate 1 未过 → 不得接真实加热器。** 若温控开关尚未到货，此项无法通过，只能继续用假负载。

### Gate 2 · 真实加热器 + PID 整定

| # | 项目 | 判据 |
|---|------|------|
| 2-1 | 首次上电 | 接真实负载后先手动确认 PA8 上电默认 0V，再启动 |
| 2-2 | 保守参数升温 | Kp=4.0 / Ki=0.05 / Kd=0，目标高出环境 10℃ |
| 2-3 | 逐步整定 | 先 Kp、再 Ki、最后 Kd；每次只改一个量 |
| 2-4 | 指标 | 超调 <2℃、稳态误差 <0.5℃、无持续振荡；记录升温曲线 |
| 2-5 | 异常验证 | 闭环中拔传感器 → 立即关断（复测 Gate 1-1） |

**注意**：Gate 2 全程必须有人值守，加热器远离易燃物，并保持 Gate 1 的过温保护有效。
